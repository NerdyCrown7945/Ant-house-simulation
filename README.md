# Ant-house-simulation

브라우저에서 실행되는 **개미굴 2D 단면(옆면) 시뮬레이션**입니다.

## 실행

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속.

## 핵심 기능

- 어항을 보듯 옆에서 보는 단면 뷰.
- 슬라이더로 맵의 가로 구간을 이동(카메라 팬).
- 개체 종류 선택 후 추가 가능: 일개미, 병정개미, 수개미, 여왕개미.
- 역할 기반 자동 행동:
  - 일개미: 주 굴착 + 흙 운반
  - 병정개미: 입구 주변 순찰/방어 성향 + 보조 굴착
  - 수개미: 상부 터널 위주 이동
  - 여왕개미: 깊은 챔버 중심 이동 + 산란
- 종류별 외형(색/크기) 차등 렌더링.
