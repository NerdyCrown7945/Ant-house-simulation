# Ant-house-simulation

브라우저에서 실행되는 2D 단면 개미굴 시뮬레이션입니다.

## 실행

```bash
python3 -m http.server 8000
```

이후 브라우저에서 `http://localhost:8000` 접속.

## 모델 개요

- 지표면 아래는 토양 셀로 구성됩니다.
- 개미는 터널을 따라 이동하며, 인접 토양의 강도/밀도/페로몬을 기반으로 굴착 여부를 확률적으로 결정합니다.
- 흙을 운반하는 개미는 위쪽(지표면)으로 복귀하려는 경향을 갖습니다.
- 챔버 형성 성향 값이 높을수록 넓은 방이 더 자주 생깁니다.
