# Ant-house-simulation

HTML/CSS/Canvas API 기반의 개미굴 2D 단면(옆면) 시뮬레이션입니다.

## 실행

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속.

## 주요 기능

- 넓은 지하 월드 + 가로 카메라 슬라이더
- 개체 수동 스폰(종류/수량 선택)
- 캐스트별 자동 행동(일개미/병정개미/수개미/여왕개미)
- 물리 시뮬레이션(흙 낙하, 모래-물 상호작용, 물 흐름)
- 산란 → 알 → 유충 → 성체 성장
- 세대별 미세 돌연변이(속도/굴착 보정)
- 콜로니 효율 점수/건강도 지표
- 지우개/보이드 도구로 지형 편집
